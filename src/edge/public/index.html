赛前

胜率期望，不是断言

结合账号总胜率、加权胜率、分舰种表现与组队结构，输出友方的胜率期望。 单场方差很大，这个数字用来判断形势，不宣称能预知输赢。

赛后

预测与结果并排对照

解析 .wowsreplay 回放拿到真实胜负与每人表现，和赛前预测放在一起， 逐场累积成一份自己的预测准确率记录。

本地

查询与推理都在本机

战绩走战舰世界官方公开 API，与常见战绩站同源；模型在本地推理， 回放文件与账号凭据不上传。

开始使用
  1. 下载安装版并完成安装，或解压便携版到任意目录，例如 D:\WowsBattleIntel
  2. 启动程序，在「设置」页确认游戏安装路径与回放目录（通常能自动识别）
  3. 开一局游戏。进入加载界面后程序自动捕获名单并给出预测，打完回到桌面即可看到赛后对照
  4. 历史回放会列在左侧，标「待解析」的条目点一下就会解析入库，旧局也能补进统计
运行要求
  • Windows 10 1903 或更高（x64）
  • 战舰世界客户端（用于定位回放目录，只读取它写出的名单文件与回放）
  • 安装版自带运行时。便携版与命令行版需要 .NET 10 桌面运行时， 启动报错时先装它
数据与隐私
  • 战绩数据通过战舰世界官方公开 API 查询，与第三方战绩网站同源
  • 预测模型在本地运行，回放文件不上传
  • 对局记录存在本机 SQLite 里，卸载或删除目录即清除
  • 可选参与对局数据协作：会上报匿名化的对局统计（账号 ID、船只、比分）， 帮助改进模型，可在设置中关闭
