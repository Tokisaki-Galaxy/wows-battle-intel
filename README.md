# wows-battle-intel

《战舰世界》战斗情报与胜负预测系统。

在 ApeRadar 的赛前水表面板之上，补上两件它没做的事：把回放文件解析成真实的战后数据，用模型在开局时给出这一局的胜率期望，并持续用真实结果校准这个预测。

## 这是什么

一个 Windows 桌面工具加一个云端协调后端，四件事：

1. **赛前预测**。开局读取对局名单，结合每个玩家的账号数据、近期状态、组队结构，输出双方胜率期望。
2. **赛后对照**。解析 `.wowsreplay` 回放，拿到真实胜负与每人表现，跟赛前预测并排显示，量化预测误差。
3. **本地采集**。把每局结果落进本地 SQLite，逐场累积带时间戳的对局记录，这是近期状态特征的唯一来源。
4. **云端协调**。Cloudflare Workers 提供玩家数据缓存、回放众包采集、模型分发，解决 WG API 限流与训练数据冷启动。

## 设计立场

- **只读，不改游戏**。只读游戏自己写出的 `tempArenaInfo.json` 和回放文件，以及公开 API，不触碰游戏进程。
- **预测是期望，不是断言**。受限于赛前可见信息，单场结果方差极大。输出校准过的胜率期望，用于辅助判断，不宣称能预知输赢。
- **校准优先于精度**。项目最有价值的产出是可公开的预测准确率与校准曲线，这是现有水表工具普遍缺失的部分。
- **持久层可替换**。数据访问藏在仓储接口后，起步用 Cloudflare D1，规模触顶时平滑切换到 Neon Postgres。

## 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 桌面客户端 | C# 14 / .NET 10 / WPF | 复用 ApeRadar 的扩展点，语言与框架一致 |
| 回放解析 | `replayshark` 外部进程 | 零移植成本，版本兼容由 wows-toolkit 维护 |
| 本地存储 | SQLite | 单机可靠、零运维、断网可用 |
| 本地推理 | ONNX Runtime | 延迟低、不占服务器、断网可用 |
| 模型训练 | Python + LightGBM | 机器学习生态成熟 |
| 边缘后端 | Cloudflare Workers | 全球分发、免费额度充足 |
| 持久层 | Cloudflare D1，预留 Neon | 起步零成本，规模可迁移 |
