## 关键风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 数据冷启动 | 训练数据不足 | 众包采集，从第一天就存逐场明细 |
| 预测客观上限 | 精度不及预期 | 定位为期望工具，校准优先 |
| 回放版本兼容 | 解析失败 | 依赖 wows-toolkit 的 gamedata，早验证 |
| D1 容量触顶 | 云端不可用 | 仓储接口抽象，预留 Neon 迁移 |
| WG API 限流 | 数据拉取失败 | 中央库缓存，本地缓存优先 |

## 产品定位提醒

预测存在客观上限。赛前拿不到走位、操作、运气。参考坦克世界 XVM 的实测，其胜率预测实际分布在 23% 到 74% 之间。因此：

- 输出的是胜率期望，不是输赢断言。
- 校准与对照能力是真正的差异点，现有水表工具普遍不公布准确率。
- 局内优势评估（参考 wows-toolkit 的 advantage 模型）与赛前预测结合，能做出随时间推进的胜率曲线，比单一数字更有价值。
