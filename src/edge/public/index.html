战舰世界战斗情报

赛前知道这一局能不能赢

本地解析对局回放，自动补齐双方玩家历史战绩，机器学习模型在加载界面给出友方胜率预测。 名单按战绩染色，海王与猴子一眼可辨。

下载最新版 GitHub 仓库 Windows x64 · 免安装 · zip 约 7 MB
运行要求
  • Windows 10 1903 或更高（x64）
  • .NET 10 桌面运行时（若打不开程序先装它）
  • 战舰世界客户端（用于定位回放目录）
安装步骤
  1. 下载并解压 zip 到任意目录，例如 D:\WowsBattleIntel
  2. 运行 WowsBattleIntel.Client.exe，首次启动在设置页填入游戏安装路径
  3. 开一局游戏，回到加载界面时程序会自动捕获对局并给出预测
数据与隐私
  • 战绩数据通过战舰世界官方公开 API 查询，与第三方战绩网站同源
  • 预测模型在本地运行，回放文件不上传
  • 可选择参与对局数据协作：上报内容仅含匿名化的对局统计（账号 ID、船只、比分），可在设置中关闭
